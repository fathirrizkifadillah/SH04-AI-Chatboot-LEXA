# Daftar Paket Harga SaaS Lexa 💳💰

Lexa menawarkan berbagai macam paket langganan yang fleksibel, disesuaikan dengan skala bisnis Anda dari startup hingga perusahaan besar (enterprise). Berikut adalah rincian harganya:

## 1. Paket Free (Gratis Selamanya)
- **Harga**: $0 / bulan
- **Batas Chat**: 500 percakapan per bulan.
- **Fitur**:
  - Chatbot basic (tanpa integrasi dokumen kustom / RAG).
  - Tampilan widget standar dengan logo Lexa.
  - Penyimpanan riwayat chat selama 7 hari.
  - Integrasi terbatas (hanya web widget).

## 2. Paket Pro (Rekomendasi untuk Bisnis Berkembang)
- **Harga**: $49 / bulan
- **Batas Chat**: 10.000 percakapan per bulan.
- **Fitur**:
  - **Custom Knowledge Base (RAG)**: Chatbot dapat menjawab menggunakan dokumen perusahaan Anda sendiri (up to 50 file).
  - Kustomisasi tampilan penuh (branding mandiri, hapus logo Lexa).
  - Integrasi dengan WhatsApp Business API dan Telegram.
  - Dasbor analisis kinerja dan sentimen pelanggan dasar.
  - Penyimpanan riwayat chat tanpa batas.
  - Dukungan email prioritas (respon < 24 jam).

## 3. Paket Enterprise (Solusi Skala Besar)
- **Harga**: Custom Pricing (Hubungi Tim Sales kami di sales@lexa.ai)
- **Batas Chat**: Tanpa batas (Unlimited).
- **Fitur**:
  - Semua fitur Paket Pro.
  - Integrasi API & Webhooks kustom ke sistem internal Anda (CRM, ERP, Billing).
  - Live Agent Handoff lanjutan dengan perutean tim otomatis.
  - Keamanan tingkat tinggi dengan SLA (Service Level Agreement) ketersediaan 99.9%.
  - Dedicated Account Manager dan dukungan 24/7 via telepon/Slack.
  - On-premise deployment option (untuk korporasi dengan regulasi data ketat).

---

## 📌 Catatan Tambahan:
- Semua paket berbayar memiliki masa uji coba gratis (*free trial*) selama 14 hari tanpa membutuhkan kartu kredit.
- Kuota chat bulanan direset setiap tanggal pembayaran awal langganan Anda.
- Jika kuota bulanan Anda habis pada Paket Pro, Anda akan dikenakan biaya tambahan senilai $0.005 per percakapan tambahan atau Anda dapat melakukan upgrade ke Paket Enterprise kapan saja.
